# Root на Яндекс Станциях

Исследовательский проект для Яндекс Станций. Здесь собраны инструкции и результаты тестов.

> **Важно:** пока подтверждена одна модель. Это Мини 2 без часов. Номер модели — **YNDX-00021**.

## Начните отсюда

**[Подробная инструкция Root](docs/root-yandex-mini-2-no-clock.md)**

Она объясняет каждый шаг. Команды сопровождаются пояснениями.

## Материалы проекта

- [Как работает механизм](docs/how-it-works.md) — DNS, OTA, Sync и ADB.
- [Диагностика ошибок](docs/troubleshooting.md) — поиск причин и решений.
- [Отчёт о тестировании](docs/test-report.md) — реальные результаты эксперимента.

## Что проверено

| Параметр | Результат |
|---|---|
| Модель | YNDX-00021 |
| Устройство | Мини 2 без часов |
| Платформа | `yandexmini_2` |
| Прошивка | `0.369.1.46.4778262943.20261013.299` |
| ADB | Сетевой порт 5555 |
| Root | `uid=0(root) gid=0(root)` |

Совместимость с другими моделями пока не подтверждена.
